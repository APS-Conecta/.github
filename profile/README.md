# APS Conecta

**Herramientas de software para la gestión interna de centros de salud familiar (CESFAM) en Chile.**
_Software tools for the internal management of Chilean primary-healthcare centres (CESFAM)._

---

## 🇨🇱 Español

**APS Conecta** desarrolla software para ordenar la **gestión interna** de un centro de salud familiar
(CESFAM): documentos, coordinación y procesos del equipo. Cada instalación atiende a **un
establecimiento**, definido en la configuración de esa instalación; el software no nombra a ninguno.

**El problema que resuelve.** La información suele vivir dispersa —en WhatsApp, correos, pendrives y
carpetas sueltas— y cada dato en su propio archivo. Eso hace que no exista una versión única y confiable,
y que la información no se pueda buscar ni analizar. APS Conecta la convierte en un espacio de trabajo
**único, ordenado, buscable y editable en conjunto**.

**Cómo lo hace.**

- **Construido sobre software libre y de código abierto**, **auto-alojado** — sin licencias pagadas.
- Centrado en la **privacidad**: pensado para operación interna. **No** es una ficha clínica y no
  almacena datos de pacientes.
- Construido sobre plataformas abiertas y consolidadas, no desde cero.

**Licencia.** El código propio de APS Conecta es **software libre**, bajo
**[AGPL-3.0-or-later](https://www.gnu.org/licenses/agpl-3.0.html)**. Los repositorios son privados,
pero la licencia es *copyleft*: quien recibe el software, o lo usa a través de la red, tiene derecho a
pedir el código fuente y a modificarlo y redistribuirlo, y ese derecho se respeta. La **identidad
visual** —logo, logo monocromo, lockup y favicon— queda reservada como marca según el artículo 7(e)
de la AGPL: la licencia del código no la cede.

**Cómo trabaja esta organización.** APS Conecta lo desarrolla una sola persona. El perfil de la
organización es público; los repositorios se mantienen **privados**. Las reglas de colaboración están
en [`CONTRIBUTING.md`](https://github.com/APS-Conecta/.github/blob/main/CONTRIBUTING.md) y la
política de seguridad en [`SECURITY.md`](https://github.com/APS-Conecta/.github/blob/main/SECURITY.md).

## 🇬🇧 English

**APS Conecta** builds software to organize the **internal operations** of a Chilean primary-healthcare
centre (CESFAM): the team's documents, coordination, and processes. Each install serves **one
establishment**, named in that install's configuration; the software itself names none.

**The problem it solves.** Information tends to live scattered — across WhatsApp, email, USB drives, and
loose folders — each fact in its own file. There's no single trusted version, and nothing can be searched
or analyzed. APS Conecta turns it into **one organized, searchable, collaboratively-editable** workspace.

**How it works.**

- **Built on free and open-source**, **self-hosted** software — no paid licenses.
- **Privacy-first**: built for internal operations. It is **not** a patient-record system and holds no
  clinical data.
- Built on established open platforms rather than from scratch.

**Licensing.** APS Conecta's own code is **free software**, under
**[AGPL-3.0-or-later](https://www.gnu.org/licenses/agpl-3.0.html)**. The repositories are private, but
the licence is *copyleft*: anyone who receives the software, or uses it over a network, is entitled to
request the source and to modify and redistribute it — and that entitlement is honoured. The **visual
identity** — logo, mono logo, lockup and favicon — is reserved as a mark under AGPL section 7(e): the
code licence does not hand it over.

**How this organization works.** APS Conecta is built by one person. The organization profile is
public; the repositories stay **private**. Collaboration rules live in
[`CONTRIBUTING.md`](https://github.com/APS-Conecta/.github/blob/main/CONTRIBUTING.md), and the
security policy in [`SECURITY.md`](https://github.com/APS-Conecta/.github/blob/main/SECURITY.md).
